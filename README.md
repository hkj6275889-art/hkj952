# 유튜브 콘텐츠 반자동화 도구

정보성 내레이션 유튜브 영상의 대본과 업로드 메타데이터(제목/설명/태그)를 만드는 과정을
반자동화하는 커맨드라인 도구입니다.

## 왜 반자동화인가

리서치, 팩트체크, 최종 편집/검수는 사람이 합니다. 이 도구가 자동화하는 부분은
검증된 사실·이야기 조각들을 몰입감 있는 서사 구조에 맞춰 조립하는 반복 작업입니다.

구조는 아래 흐름을 따릅니다 (레퍼런스 영상 구조 분석 기반):

1. 훅 - 공감되는 질문 던지기
2. 핵심 수치/사실 제시
3. 문제의 구조를 단계적으로 심화 (벽 2~3개)
4. 전환 - "반대편에 다른 길이 있다"
5. 자연/생체 비유로 해법의 실마리 제시
6. 비전 제시 (핵심 요소 3가지로 구조화)
7. 역사적 일화 / 과학적 근거
8. 미래 상상 시나리오
9. 사회/권력 구조 변화 논의
10. 인간의 역할 재정의
11. 오늘부터 실천 가능한 행동 리스트
12. 공유·구독 유도 + 마무리

## 사용법

### 1. 설치

```
pip install -r requirements.txt
```

### 2. 리서치 내용을 YAML로 정리

`templates/sample_input.yaml` 참고. 같은 구조를 유지한 채 직접 리서치한 주제로
내용만 교체한 새 YAML 파일을 작성하세요.

### 3. 대본 초안 생성

```
python generate_script.py --input templates/sample_input.yaml --output script.md
```

각 섹션마다 예상 발화 시간(누적 타임스탬프)이 함께 출력됩니다. 한국어 평균 발화 속도
추정치 기준이며, 실제 녹음 속도에 따라 오차가 있습니다.

### 4. 대본 검수 및 수정 (사람)

생성된 초안은 뼈대일 뿐입니다. 사실관계, 어조, 문장은 직접 검토해야 합니다.
특히 과학적으로 검증되지 않았거나 논쟁적인 주장(특정 주파수의 치유 효과, 형태공명,
텔레파시적 상호작용 등)은 사실처럼 단정하지 말고 "~라는 주장이 있다", "가설 단계다"처럼
명확히 구분해서 표현하는 것을 권장합니다.

### 5. 업로드 메타데이터 생성

```
python generate_metadata.py --input templates/sample_input.yaml --output metadata.md
```

제목 후보 5개, 설명란 초안, 태그 목록을 생성합니다. 최종 선택은 사람이 합니다.

## 파일 구성

- `generate_script.py` - YAML 입력 → 대본 초안(Markdown)
- `generate_metadata.py` - YAML 입력 → 제목/설명/태그 후보
- `templates/sample_input.yaml` - 입력 스키마 예시
- `requirements.txt` - 의존성 (PyYAML)
